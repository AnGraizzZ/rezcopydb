### Задание 3. MySQL

3.1. С помощью официальной документации приведите пример команды инкрементного резервного копирования базы данных MySQL. 
---
mysql не поддерживает инкрементное копирование в стандартном понимании. Он создает бинарные лог файлы с помощью которых можно будет произвести инкрементное восстановление до нужного состояния. В mysql версии 9.7 бинарное логирование используется по умолчанию. так же логирование можно включить через файл конфигураций
Нужно выполнить полное резервное копирование со следующими флагами

`mysqldump -u root -p --all-databases --master-data=2 --flush-logs > full.sql`

--master-data=2 - флаг записывает в бэкап информацию о последнем логфайле, что позволит в дальнейшем исключить лишние логфайлы

--flush-logs - закрывает запись в последний записываемый лог и начинает записывать новый, что позволит отделить логи до резервного копирования и после
